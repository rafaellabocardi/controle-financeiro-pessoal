# Sistema de Controle Financeiro Pessoal

## Sobre o projeto

Projeto desenvolvido para a disciplina de Projeto de Software, do curso de Engenharia da Computação da UFBRA.

O sistema tem como objetivo auxiliar pessoas na organização de suas finanças pessoais, permitindo o registro de receitas e despesas e o acompanhamento do saldo financeiro.

## Objetivo

Desenvolver uma aplicação web simples e intuitiva para facilitar o controle financeiro pessoal e ajudar os usuários a compreenderem melhor suas movimentações financeiras.

## Usuários

Pessoas que desejam organizar seus gastos, registrar suas receitas e acompanhar seu orçamento mensal.

## Funcionalidades iniciais

- Cadastro de usuários.
- Login e logout.
- Cadastro de receitas e despesas.
- Edição e exclusão de lançamentos.
- Organização por categorias.
- Filtros por mês e ano.
- Visualização do resumo financeiro.

## Tecnologias previstas

- React.js
- C# / ASP.NET Core Web API
- SQL Server
- Git e GitHub

## Escopo

A primeira versão será voltada ao controle manual de receitas e despesas, sem integração com bancos ou serviços financeiros externos.
